Web1 · read

The static page

1991 · Tim Berners-Lee · CERN

HTTP, HTML, the URL. One-way information flow. The user reads what the publisher wrote. Nothing routes; nothing personalizes; nothing remembers. The page is the page.

The substrate's analog of Web1 is aerosol-exempt static: marketing surface that operators can read without authenticating. airlocklabs.io is the canonical aerosol layer. No gate, no ledger, no auth.

Web2 · read · write

Public input layer

2004 onward · social platforms · UGC

Two-way. Users wrote back. Comments, posts, likes, shares. The platform aggregated and sorted. Most of Web2's value flowed to a small number of platforms; most of the user's data flowed there too.

The substrate's Web2 node is doyoulikedags.xyz — a DAG-based signal generation surface. Free tier onboarding. Persona Bot Atlas (the substrate's Tier-1 entry agent). Signals are produced here and routed upstream into the audited substrate layers.

Web3 · own

Settlement layer

2014 onward · Ethereum · DIDs · tokens

The user owned. Cryptographic identity, on-chain assets, decentralized wallets. Ownership decoupled from platform consent. The economic surface separated from the social surface.

The substrate's Web3 node is amerikana.store — a Grand Exchange order-book marketplace (RuneScape GE server model). Three-token economy on Cosmos SDK rails: $MOTTO (Quantum-Safe stable-coin foundation), $MOTION (incentive / participation), $DREAM (compute-and-creativity unit on WEFT). Constellation Credits remain off-chain. Skills paid via the .diy marketplace; avatars free at onboarding.

Web4 · filter · express

Provenance + filter layer

2024 onward · provenance · expression governance

Substrate-level routing between public input and audited storage. Provenance filters at the ACODE↔BCODE boundary; six rules govern what crosses. Anomalous outputs blocked inline at the compute layer. The Untangler enforces the closure-band acceptance rule; the Provenance Filter enforces the policy schema.

The substrate's Web4 node is brainbrigade.xyz — the cohort surface for independent practitioners federated through open-source contribution graphs. First node in the inbound routing chain. Inputs from doyoulikedags.xyz arrive here, are policy-checked, and route forward to the audited storage layer.

Substrate role: cohort surface · provenance filter · routing chain entry
domain brainbrigade.xyz landing shipped
Web5 · inhabit · identify

Spacebar — operator console + audited storage

2026 onward · operator-resident shells · DID-bonded sessions

The operator's authenticated console. Biometric-gated session start. Every interaction signs a BCODE closure; every closure is checked against the acceptance band before propagation. Operators run cryptographic-identity-bound sessions; outputs are auditable end-to-end.

The substrate's Web5 node is amerikana.space — Spacebar. The first surface that stores the routed signals after Brain Brigade's provenance check. Storage runs on Nerv OS (the production runtime layer hosting nerv.rest, the BCODE audit endpoint). The OS itself is Amerikana Online.

The runtime layer for Amerikana Online

Spacebar (amerikana.space) is the operator-facing surface; the storage and execution run on Nerv OS — the substrate's production runtime layer. Nerv OS hosts nerv.rest, the BCODE audit endpoint where signed closures land. The OS itself is named Amerikana Online and provides the runtime context for the entire substrate stack.

noconflict.dev · the completion-facade

The broken page is the proof.

noconflict.dev's landing page never sells. The NPM package is "broken." Visitors arrive, find nothing for sale, and leave.

That is the design. NoConflict's whole purpose is captured in two words: nc push → done. no bodies. The page is not broken because we forgot to finish it. The page is broken because the agent already finished. Selling would be a leak — there's nothing left to sell, because there are no merge conflicts to resolve, because the agent already resolved them.

The facade is operator-grade. It tells the visitor: this is what completion looks like. A page that doesn't ask for your email is a page that has already won.
